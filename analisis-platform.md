# Analisis Komparatif Platform

## 1. Perbandingan Platform Web, Desktop, dan Mobile

| Aspek           | Web                                                                       | Desktop                                                                 | Mobile                                                             |
| --------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Bahasa utama    | HTML, CSS, JavaScript                                                     | Java, C#, C++, Python                                                   | Kotlin, Java, Swift, Dart                                          |
| Arsitektur      | Client-server, diakses melalui browser                                    | Aplikasi berjalan pada sistem operasi komputer                          | Aplikasi berjalan pada sistem operasi perangkat mobile             |
| Cara distribusi | Melalui URL atau hosting web                                              | Melalui installer atau toko aplikasi desktop                            | Melalui Play Store, App Store, atau file instalasi                 |
| Keunggulan      | Mudah diakses tanpa instalasi khusus dan dapat digunakan lintas perangkat | Dapat memanfaatkan sumber daya komputer dan mendukung pekerjaan offline | Praktis dibawa, mendukung fitur perangkat seperti GPS dan kamera   |
| Keterbatasan    | Bergantung pada browser dan koneksi internet untuk fitur online           | Umumnya perlu instalasi dan penyesuaian sistem operasi                  | Memiliki keterbatasan layar, baterai, dan kompatibilitas perangkat |
| Contoh aplikasi | Google Docs, Gmail                                                        | Microsoft Word, Visual Studio Code                                      | WhatsApp, Google Maps                                              |

## 2. Analisis

Platform web cocok untuk aplikasi yang membutuhkan akses mudah dari berbagai perangkat. Pengguna cukup membuka browser tanpa harus memasang aplikasi secara khusus. Namun, beberapa fitur dapat bergantung pada koneksi internet dan kemampuan browser.

Platform desktop cocok untuk aplikasi yang membutuhkan kemampuan komputasi komputer dan fitur sistem operasi. Aplikasi desktop dapat mendukung penggunaan offline, tetapi umumnya memerlukan proses instalasi dan pembaruan tersendiri.

Platform mobile dirancang untuk perangkat seperti smartphone dan tablet. Platform ini mendukung penggunaan saat bepergian serta integrasi dengan fitur perangkat, misalnya kamera, GPS, dan notifikasi. Kekurangannya adalah ukuran layar yang lebih terbatas serta penggunaan baterai dan sumber daya perangkat.

Pemilihan platform harus disesuaikan dengan kebutuhan pengguna, fitur aplikasi, biaya pengembangan, dan kemudahan pemeliharaan.
